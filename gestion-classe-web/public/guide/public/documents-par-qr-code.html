Documents par QR code

Chaque fiche imprimée depuis l'éditeur de cours porte en haut à droite un petit QR code « Version couleur ». L'élève le scanne avec son téléphone et lit la fiche en couleur, toujours à jour, sans compte ni code.

Le QR code « Version couleur » sur la feuille

OrdinateurMes cours › document › Fichier › Imprimer

Une fiche photocopiée en noir et blanc perd ses couleurs et ses schémas. Le QR code imprimé dessus ramène l'élève à la version en couleur, sur son téléphone. Rien à régler : il se pose tout seul.

  1. Ouvrir la fiche dans l'éditeur de cours et choisir l'onglet Fichier du ruban.
  2. Cliquer Imprimer (ou Exporter en PDF). La fenêtre « Imprimer le cours » s'ouvre.
  3. Choisir la version, le nombre de pages par feuille et les couleurs : Noir et blanc convient à la photocopieuse.
  4. Cliquer Imprimer. À la première impression, le lien du QR code est créé juste avant.
  5. La première feuille porte, en haut à droite dans la marge, le QR code et la légende Version couleur. Il résiste à la photocopie.

À savoir

  • Le QR code n'existe que sur le papier et dans le PDF : on ne le voit jamais à l'écran de l'éditeur.
  • Une fiche posée sur un cours de l'emploi du temps ouvre toujours l'original de la bibliothèque.
  • Une correction, un corrigé, une copie modèle, une évaluation ou un devoir noté (titre commençant par Entraînement noté, Contrôle, Interro, Devoir surveillé ou DS) n'ont jamais de QR code.
  • Le lien ne change plus une fois créé : les feuilles déjà distribuées restent valables, même après des retouches du document.

Scanner la feuille et lire en couleur

Sans compteÉlèveAppareil photo du téléphone › QR code

L'élève vise le QR code de sa feuille : la fiche s'ouvre sur son téléphone, en couleur, sur une seule colonne. Aucune application à installer, aucun code à taper.

  1. Ouvrir l'appareil photo et viser le QR code en haut à droite de la feuille, puis toucher le lien qui apparaît.
  2. La page s'ouvre (« Ouverture du document… ») sur la vue Téléphone : la fiche en une colonne, avec ses couleurs, ses encadrés et ses images.
  3. Faire défiler du doigt. On peut zoomer à deux doigts ; un tableau trop large défile de côté.
  4. Toucher Pages A4 pour voir les feuilles telles qu'elles ont été imprimées.
  5. Imprimer / PDF prépare les feuilles A4 (« Préparation… ») puis ouvre la fenêtre d'impression du téléphone.

À savoir

  • Ce que voit qui a la feuille : le texte et les images de cette fiche, dans sa dernière version. Rien d'autre : aucun élève, aucune note, aucun autre document.
  • Ce qui ne sort jamais : corrections, corrigés, copies modèles et évaluations (le titre est relu à chaque scan : une fiche renommée « (correction) » après coup n'est plus servie), écrans projetés, liens vers des sites, annotations de l'enseignant, encarts de tableau blanc.
  • Les zones d'écriture et les pointillés de réponse sont retirés : ils ne servent à rien sur un téléphone.
  • Si l'enseignant modifie la fiche, l'élève voit la nouvelle version : la page se relit quand on y revient après une minute.
  • Messages possibles : « Ce lien ne fonctionne plus. » (document supprimé ou devenu une correction), « Pas de connexion. », « Le document ne répond pas pour le moment. ».
  • La page demande aux moteurs de recherche de ne pas l'indexer.

La version « sur mesure »

Sans compteÉlèveQR code de la feuille

Pour certaines fiches, l'enseignant fait écrire par Claude une page pensée pour le téléphone : schémas à toucher, réponses à révéler, animations. Le même QR code l'ouvre à la place de la version automatique, sans réimprimer la feuille.

  1. Scanner le QR code : la page sur mesure s'ouvre en plein écran, avec son propre graphisme.
  2. Toucher les éléments de la page : ici, un repère du schéma affiche son explication.
  3. Le petit bouton Version simple, en bas à droite, ramène à la version automatique, en une colonne.
  4. La version simple s'affiche, avec ses boutons habituels. Version sur mesure y retourne.
  5. La page sur mesure se rouvre, depuis le début.

À savoir

  • La page sur mesure tourne dans un cadre isolé : elle ne peut rien lire de l'application, ni rien envoyer sur Internet. Elle ne contient que la fiche.
  • Elle s'ouvre seulement par le QR code de la feuille, jamais par le lien lecture seule du cahier de texte.
  • Mêmes interdits que la version automatique : une correction ou une évaluation n'a jamais de page sur mesure.
  • Elle ne se fabrique pas dans le site : c'est Claude qui l'écrit à la demande de l'enseignant, puis la dépose.

Savoir quelle version ouvre le QR code

OrdinateurÉditeur de cours › barre de titre

Une étiquette, à côté du titre du document, dit ce que voient les élèves qui scannent la feuille : la version automatique ou une version sur mesure, et si celle-ci est encore à jour.

  1. Version mobile : automatique : le QR code ouvre la version faite par l'application, qui suit chaque retouche du document.
  2. Quand Claude a déposé une page sur mesure, l'étiquette devient Version mobile : sur mesure.
  3. Après une retouche du document, elle passe à Version mobile : plus ancienne que le document : la page sur mesure ne suit pas les retouches. Cliquer dessus.
  4. Voir ouvre la page du QR code ; Garder dit qu'elle convient encore au document.
  5. Revenir à l'automatique retire la page sur mesure, après confirmation : le QR code ouvre de nouveau la version de l'application.

À savoir

  • Rien n'est affiché pour une correction ou une évaluation : elles n'ont pas de QR code.
  • Une copie posée sur l'emploi du temps montre la version de son original, celle que sert le QR code.
  • Une page retirée ne se récupère pas : il faut la faire déposer de nouveau par Claude.
  • Le QR code d'une feuille déjà imprimée ne se coupe pas depuis le site ; il ne mène plus à rien si le document est supprimé.

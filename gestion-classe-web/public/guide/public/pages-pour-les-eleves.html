Pages pour les élèves

Ce que l'élève ouvre sans compte en dehors de son espace : la page web d'une correction projetée en classe, la page qui envoie les photos d'une copie depuis un téléphone, et la page de dépannage quand l'application reste bloquée sur une ancienne version.

Exporter une page web pour les élèves

OrdinateurTableau blanc › Fichier › Exporter (PDF ou page web)

Les écrans d'une séance, souvent une correction, deviennent un seul fichier que l'élève ouvre chez lui : écrans dans leur état final, animations à rejouer, bouton pour imprimer.

  1. Dans le tableau blanc, ouvrir l'onglet Fichier.
  2. Cliquer Exporter (PDF ou page web). La fenêtre « Exporter » s'ouvre.
  3. Choisir Page web pour les élèves (« corrigé, animations jouables, bouton Imprimer »). Sans l'encre retire ce qui a été écrit au stylet.
  4. Cocher les écrans à garder : Toutes, Aucune ou Celle-ci.
  5. Cliquer Exporter 3 pages : un fichier « … - élèves.html » arrive dans les téléchargements, à déposer sur l'ENT, dans Pronote ou sur une clé USB.

À savoir

  • La page montre la version corrigée : les boutons « pour le prof » sont appuyés dans l'ordre (ce qu'ils montrent est là, ce qu'ils cachent a disparu), et ne sont pas dessinés ; caches et trous sont ouverts.
  • Ce qui reste masqué sans bouton (brouillon, variante) reste masqué.
  • Un fichier donné ne se reprend pas : il n'y a pas de lien à couper. Vérifier les écrans avant de le déposer, et ne jamais y laisser un nom d'élève écrit au tableau (cocher « Sans l'encre » au besoin).
  • Le fichier contient tout : il s'ouvre sans connexion et sans compte.

La page web côté élève

Sans compteÉlèveENT, Pronote ou clé USB › fichier .html

L'élève ouvre le fichier dans n'importe quel navigateur, sur ordinateur, tablette ou téléphone, et retrouve la correction vue en classe.

  1. Ouvrir le fichier : la barre du haut porte le titre du tableau et le bouton Imprimer. Aucune connexion n'est nécessaire.
  2. Faire défiler les écrans. Un bouton de sommaire posé sur un écran mène à l'écran visé.
  3. Sous une animation : Étape suivante ▶, ◀ Étape précédente, le compteur « 2 / 4 » et ↺ Rejouer.
  4. Imprimer : deux écrans par feuille A4, sans aucun bouton ; les animations sont imprimées en image fixe.

À savoir

  • Le fichier ne contient que les écrans exportés : aucun nom d'élève, aucune note, aucun lien vers l'application.
  • Il ne se met pas à jour : une correction modifiée ensuite demande un nouvel export.

Envoyer une copie par QR code

OrdinateurSans compteÉvaluation › Voir les copies › Ajouter une copie › QR code (téléphone)

Une copie papier se photographie avec n'importe quel téléphone, celui de l'élève ou celui de l'enseignant : les pages arrivent directement dans l'évaluation, prêtes pour la correction.

  1. Sur l'ordinateur, dans « Ajouter une copie · Lina BO », choisir l'onglet QR code (téléphone). Le QR code s'affiche.
  2. Scanner le QR code avec le téléphone : la page « Gestion Classe · envoi d'une copie » montre le pseudonyme de l'élève, la classe et l'évaluation.
  3. Toucher Photographier une page, une fois par page. Chaque photo devient une vignette « Page 1 », « Page 2 », avec ⟳ (tourner) et × (retirer).
  4. Toucher Envoyer 2 page(s) : « Envoi… 1/2 », puis « 2 page(s) envoyée(s). Tu peux en ajouter d'autres, ou fermer cette page. »
  5. Sur l'ordinateur : « 2 page(s) reçue(s) ». Fermer la fenêtre quand c'est fini : le QR code ne marche plus.

À savoir

  • Ce que voit qui scanne : le pseudonyme de cet élève (prénom et deux lettres), la classe et le nom de l'évaluation. Ni note, ni correction, ni autre copie, ni liste de la classe.
  • Pour une évaluation à plusieurs versions du sujet, indiquer d'abord la version : le QR code s'affiche ensuite.
  • Le QR code ne vaut que pour cet élève : 15 minutes, 8 pages au plus. Fermer la fenêtre sur l'ordinateur le désactive aussitôt.
  • Les photos sont réduites sur le téléphone avant l'envoi (5 Mo au plus par page). Messages possibles : « Ce QR code a expiré ou a été fermé sur l'ordinateur. Génère-en un nouveau. », « Image illisible : reprends la photo. ».
  • Les copies photographiées sont effacées 30 jours après.

Numériser les copies de toute la classe

TéléphoneSans compteÉvaluation › Ajouter les copies de la classe › QR code (téléphone)

Un seul QR code pour tout le paquet : le téléphone enchaîne les élèves, copie après copie. Pratique pour l'enseignant, ou pour un élève chargé du ramassage.

  1. Scanner le QR code de « Ajouter les copies de la classe » : « Gestion Classe · copies de la classe », carte Choisis la copie.
  2. Toucher le nom de l'élève. Les élèves sans copie viennent d'abord ; ceux déjà photographiés portent « 2 p. » en vert. Une copie sans nom lisible part par Pas de nom (copie à identifier plus tard).
  3. « Copie de Noé MA » : photographier les pages, puis Envoyer 2 page(s).
  4. Élève suivant → passe au prochain élève sans copie. ← Liste des élèves revient à la liste.

À savoir

  • Ce que voit qui scanne : la liste des élèves attendus pour cette évaluation, sous leur pseudonyme, et le nombre de pages déjà envoyées. Jamais les photos déjà envoyées, ni les notes. Ce QR code ne se confie donc qu'à un élève de la classe.
  • Il vaut 1 heure et 200 pages ; fermer la fenêtre sur l'ordinateur le désactive.
  • Les copies « sans nom » se rattachent ensuite à un élève, sur l'ordinateur.

Si l'application ne se met pas à jour

Sans compteÉlèveqwetsh.github.io/gestion-classe/sw-reset.html

Le site se garde en mémoire sur le téléphone pour s'ouvrir vite. Il arrive qu'un téléphone reste bloqué sur une ancienne version : une page de dépannage efface cette mémoire.

  1. Donner à l'élève l'adresse qwetsh.github.io/gestion-classe/sw-reset.html (aucun lien dans l'application ne la propose).
  2. La page « Réinitialisation du cache » efface tout de suite la mémoire du site sur cet appareil et dit ce qu'elle a fait (le message garde des termes techniques : « service worker(s) désinscrit(s) », « cache(s) vidé(s) »).
  3. Comme indiqué, fermer complètement l'onglet du navigateur.
  4. Rouvrir l'application, ou toucher Ouvrir l'espace élève : la dernière version se charge.

À savoir

  • Seule la mémoire du site sur cet appareil est vidée : le thème choisi par l'élève reste, et ses notes ne sont pas sur le téléphone mais sur le serveur.
  • L'élève devra peut-être retaper son code à 6 chiffres (ou scanner sa carte QR).
  • À essayer après un simple rechargement de la page, quand celui-ci ne suffit pas.

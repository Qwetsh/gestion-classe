Pronote

La liaison avec Pronote lit l'emploi du temps de l'enseignant, semaine par semaine, et le met sur l'accueil. Les notes passent par fichier dans un sens (export Pronote vers le carnet) et par copier-coller dans l'autre. L'application n'écrit jamais elle-même dans Pronote.

Ouvrir la page Pronote

OrdinateurPlus › Pronote

La page qui relie son compte Pronote à l'application, pour en lire l'emploi du temps.

  1. Dans le menu, ouvrir Plus puis Pronote.
  2. « Chargement du module Pronote... » : l'outil qui dialogue avec Pronote n'est chargé qu'à la demande.
  3. Non connecté, la page présente la carte Connexion Pronote (« Compte enseignant ») et ses deux façons de se connecter.
  4. Le sous-titre annonce « Emploi du temps et import de classes ». En réalité, la page montre l'emploi du temps et les noms de classes, sans rien importer.

À savoir

  • Limite actuelle : malgré son sous-titre, la page n'importe ni classes ni élèves. Les élèves s'importent par fichier dans Classes et plans.
  • Si le chargement échoue, un bandeau rouge l'indique (« Erreur de chargement du module Pronote : … »).
  • Les libellés de cette page sont écrits sans accents dans l'application (« Deconnecter », « Connecte a Pronote ! ») ; ils sont cités tels quels.
  • Réservé aux comptes enseignants.

Se connecter avec le QR code de Pronote

OrdinateurTéléphonePronote › QR Code (ENT/MBN)

La voie à prendre quand l'établissement passe par un ENT : on utilise le QR code de connexion que fabrique l'application Pronote du téléphone.

  1. L'onglet QR Code (ENT/MBN) est ouvert par défaut. L'encadré « Comment faire » résume : dans l'app Pronote du téléphone, paramètres, « Generer un QR code », choisir un code à 4 chiffres, puis lire le QR code avec une app de scan.
  2. Coller le texte lu dans le QR code dans Contenu du QR code (JSON).
  3. Saisir le Code PIN (4 chiffres) choisi dans Pronote ; seuls les chiffres sont acceptés.
  4. Se connecter via QR Code : « Connexion... », puis « Connecte a Pronote ! ».

À savoir

  • Le QR code de Pronote expire vite : le coller peu après l'avoir généré, sinon « Code PIN incorrect ou QR code expire ».
  • Autres messages : « Donnees QR invalides. Copiez le contenu JSON du QR code. », « Le code PIN doit etre 4 chiffres », « Impossible de joindre le serveur Pronote. ».
  • La note « Vos donnees ne sont pas stockees » est inexacte : de quoi se reconnecter est gardé dans ce navigateur (voir Reconnexion automatique).

Se connecter avec ses identifiants

OrdinateurPronote › Identifiants directs

Pour un établissement qui autorise la connexion à Pronote sans passer par un ENT.

  1. Onglet Identifiants directs : l'encadré orange prévient que ce mode ne marche que si l'établissement autorise la connexion directe ; avec un ENT, prendre le QR code.
  2. Renseigner l'URL Pronote de votre etablissement (de la forme https://…index-education.net/pronote/).
  3. Puis l'Identifiant et le Mot de passe Pronote.
  4. Se connecter (ou Entrée dans le mot de passe). Le bouton reste grisé tant qu'un champ manque.

À savoir

  • Messages possibles : « Remplissez tous les champs », « Identifiants incorrects », « Impossible de joindre le serveur Pronote. Verifiez l'URL. ».
  • Le mot de passe n'est pas conservé. En revanche, contrairement à la note sous le bouton, la connexion n'est pas « directe » : elle passe par le serveur de l'application (voir la fiche suivante).

La reconnexion automatique

OrdinateurPronote et Accueil, à l'ouverture

Une fois connecté, on n'a plus à refaire le QR code ni à retaper son mot de passe sur ce navigateur.

  1. À la visite suivante, la page tente de se reconnecter seule : le bouton affiche « Connexion... ».
  2. Si la connexion est encore valable : « Reconnexion automatique reussie », et l'emploi du temps s'affiche.
  3. Sur un autre ordinateur, ou un autre navigateur, il faut se connecter de nouveau : la mémoire est propre à chaque navigateur.

À savoir

  • Le navigateur garde l'adresse Pronote, l'identifiant, le type de compte et un jeton de connexion renouvelé à chaque visite ; jamais le mot de passe.
  • Si la reconnexion échoue, cette mémoire est effacée sans message et le formulaire revient. L'accueil tente aussi la reconnexion et abandonne au bout de 8 secondes, sans message.
  • Deconnecter efface la mémoire du navigateur ; rien n'est révoqué côté Pronote.
  • Un navigateur ne peut pas interroger Pronote directement : les demandes passent par le serveur de l'application, réservé aux enseignants connectés. Seules les adresses Pronote en https hébergées chez Index Éducation sont admises ; sinon « Cette adresse Pronote n'est pas reconnue. Vérifiez l'adresse, ou demandez à l'ajouter. ». Session de l'application expirée : « Reconnectez-vous à Gestion Classe pour utiliser Pronote. ».

Le compte connecté et les classes détectées

OrdinateurPronote, une fois connecté

Vérifier sur quel compte et quel établissement on est connecté, voir comment Pronote nomme ses classes, et se déconnecter.

  1. En haut : l'initiale sur fond vert, le nom affiché par Pronote et l'établissement.
  2. Classes detectees cette semaine : les noms de classes et de groupes tels que Pronote les écrit, pour les cours de la semaine affichée.
  3. Changer de semaine change la liste (ici, la semaine suivante ajoute un groupe).
  4. Deconnecter vide l'emploi du temps, efface la mémoire de connexion et ramène au formulaire, sans confirmation.

À savoir

  • Aucune action d'import n'est proposée ici. Le rattachement des noms Pronote aux classes de l'application se règle dans Réglages › Emploi du temps.
  • L'encart n'apparaît que si la semaine affichée contient des cours.

L'emploi du temps de la semaine

OrdinateurPronote, une fois connecté

Ses cours Pronote, semaine par semaine : matière, classes et groupes, salle, horaire et annulations.

  1. À la connexion, la semaine en cours s'affiche (« Semaine du 23 nov. »).
  2. Le jour courant est surligné en indigo.
  3. Chaque cours : la matière en gras, les classes et groupes en indigo, la salle en gris et l'horaire, sur la couleur donnée par Pronote.
  4. Un cours annulé passe en rouge pâle, à demi effacé, avec « (Annule) » après la matière.
  5. → et ← changent de semaine ; la pastille Aujourd'hui ramène à la semaine en cours.

À savoir

  • Un cours se place dans la ligne de son heure de début (un cours de 8 h 30 est dans la ligne 8:00) ; la grille ne montre pas sa durée.
  • Samedi et dimanche ne sont pas affichés. Une semaine vide affiche « Aucun cours cette semaine ».
  • En cas de problème : « Erreur lors du chargement de l'emploi du temps ».

L'encart « Pronote non connecté »

OrdinateurBarre latérale, sur toutes les pages

Un rappel discret, en bas de la barre latérale, tant que Pronote n'est pas relié dans ce navigateur.

  1. Au-dessus du compte, un petit encadré orangé : « Pronote non connecté ».
  2. Le lien Connecter ouvre la page Pronote.
  3. La croix (« Masquer pour cette session ») le cache jusqu'à la fermeture de l'onglet ou du navigateur.

À savoir

  • « Connecté » veut seulement dire qu'une mémoire de connexion existe dans ce navigateur : même expirée, elle masque l'encart.
  • Barre latérale réduite : seule l'icône reste, avec l'infobulle « Pronote non connecté — Connecter ».
  • Sur un écran étroit (moins de 1024 pixels de large), la barre latérale laisse place à une barre du haut, où l'encart n'apparaît pas.

Pronote sur l'accueil

OrdinateurAccueil › emploi du temps de la semaine

Une fois Pronote connecté, l'accueil montre les cours réels de la semaine, sans aucune saisie.

  1. Le grand emploi du temps de l'accueil se remplit avec les cours lus dans Pronote.
  2. Chaque cours porte la classe de l'application qui lui correspond : les noms Pronote sont rattachés aux classes par la table de correspondance de Réglages › Emploi du temps.
  3. Le sous-titre « Demain » ou « Prochaine séance » s'appuie sur ces mêmes cours.
  4. Sans Pronote, ou s'il ne répond pas en 8 secondes, l'accueil prend l'emploi du temps importé par fichier (.ics exporté de Pronote), sinon rien.

À savoir

  • Ordre des sources : Pronote connecté, puis fichier .ics importé, puis rien.
  • L'accueil se reconnecte seul, sans message ; il suffit de s'être connecté une fois sur la page Pronote de ce navigateur.

Importer un export de notes Pronote

OrdinateurÉvaluations › Carnet et fiches › carnet › ⋯

Récupérer dans le carnet des notes déjà saisies dans Pronote, à partir du fichier « Notes d'une classe » exporté de Pronote.

  1. Dans le carnet de la classe, ouvrir le menu ⋯ (« Sauvegarder les notes, importer un export Pronote »)…
  2. … et choisir Importer un export Pronote (CSV) : les notes iront dans la classe et le trimestre affichés.
  3. Dans Importer depuis Pronote, choisir le fichier .csv. Un résumé s'affiche : « notes_4B.csv — 25 élèves, 2 évaluation(s). 23 reconnus, 2 sans correspondance. »
  4. Pour chaque évaluation trouvée : la cocher ou non, puis Créer une nouvelle évaluation ou Compléter une évaluation existante. Un avertissement compte les notes du carnet qui seraient remplacées.
  5. Importer : « Import… », évaluation par évaluation. Annuler ne change rien.

À savoir

  • Rien n'est écrit avant « Importer », et l'écriture se fait dans l'application, jamais dans Pronote.
  • Les élèves sont reconnus par leur pseudonyme (prénom et deux premières lettres du nom, sans accents) ; deux élèves au même pseudonyme ne sont pas importés.
  • Le fichier Pronote contient les vrais noms : ils s'affichent dans la liste des élèves non importés de cette fenêtre, mais ne sont jamais enregistrés.
  • Absent, dispensé, non rendu sont reconnus ; la colonne « Moyenne » n'est jamais prise pour une note. Une évaluation de même date et même barème est proposée d'office.

Copier une colonne de notes pour Pronote

OrdinateurCarnet › en-tête d'une évaluation › Copier pour Pronote

Reporter les notes d'une évaluation dans Pronote sans les retaper : toute la colonne part dans le presse-papiers, prête à coller.

  1. Ouvrir le menu de l'en-tête de colonne de l'évaluation…
  2. … et choisir Copier pour Pronote (« la colonne des notes, dans l'ordre de Pronote »).
  3. La fenêtre Copier pour Pronote · 4B explique : notes sur 20, une par ligne, dans l'ordre alphabétique des noms ; dans Pronote, ouvrir la saisie du devoir, cliquer la case du premier élève et coller (Ctrl+V), puis vérifier la première et la dernière ligne.
  4. Le tableau numéroté montre ce qui sera copié. Les lignes surlignées sont à vérifier : l'application ne connaît que les deux premières lettres du nom. Une note en brouillon est signalée.
  5. Copier la colonne (25 lignes) : le bouton devient « Copié ». Il reste à coller dans Pronote soi-même.

À savoir

  • C'est la seule façon de faire passer des notes vers Pronote : rien ne sort de l'application, le texte va dans le presse-papiers et l'enseignant le colle.
  • Chaque ligne porte la note brute sur le barème (virgule décimale), un code (« Abs », « Disp », « N.Rdu », « N.Rdu0 ») ou reste vide.
  • Toute la classe est copiée, même pour une évaluation de demi-groupe ; les élèves témoins sont exclus.
  • Si le navigateur refuse la copie : « Le navigateur a refusé la copie : sélectionne la colonne à la main. ». Même action dans le menu « Plus d'actions » de la fiche d'évaluation.

Ce que la liaison avec Pronote fait, et ne fait pas

OrdinateurEnsemble des usages de Pronote

Pour savoir à quoi s'attendre : ce qui est lu en direct, ce qui passe par fichier, et ce qui n'existe pas.

  1. Lu en direct : l'emploi du temps (page Pronote et accueil).
  2. Lu en direct : le nom de l'enseignant et de l'établissement.
  3. Lu en direct : les noms de classes et de groupes des cours.
  4. Par fichier : les notes (export CSV vers le carnet) et l'emploi du temps de l'année (fichier .ics, Réglages).
  5. Écrit dans Pronote : rien, directement. Seulement des colonnes de notes copiées, que l'enseignant colle lui-même.

À savoir

  • Limite actuelle : pas d'import des classes ni des élèves depuis Pronote, malgré le sous-titre de la page ; les élèves s'importent par fichier CSV ou Excel dans Classes et plans.
  • Non disponible dans cette version : la lecture de l'agenda, du cahier de textes ou des devoirs de Pronote, et toute saisie automatique de notes ou d'appréciations dans Pronote.
  • L'outil qui dialogue avec Pronote n'est pas officiel : une mise à jour de Pronote peut le casser du jour au lendemain.

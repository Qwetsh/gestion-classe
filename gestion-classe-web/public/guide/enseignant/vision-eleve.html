Vision élève

Pour savoir ce que voit un élève, plus besoin de prendre un téléphone et de chercher son code : la page met côte à côte les codes de toutes vos classes et un téléphone qui affiche le vrai espace élève. Un clic sur un élève, et son espace s'ouvre, déjà connecté.

Menu Classes › Vision élèveOrdinateurLe vrai espace élève, dans un téléphone simulé

Ouvrir Vision élève

OrdinateurClasses › Vision élève

Voir l'espace élève exactement comme un élève le voit sur son téléphone, sans téléphone ni code à chercher : la page réunit les codes de toutes vos classes et un téléphone simulé.

  1. Dans le menu, ouvrir Classes puis Vision élève, juste sous Suivi élèves (icône de téléphone).
  2. Sous le titre, une phrase dit ce qu'est la page, et prévient que ce qu'on fait dans le téléphone compte pour l'élève.
  3. À gauche : les codes de connexion des élèves de toutes vos classes, rangés par classe.
  4. À droite : un téléphone qui affiche le vrai espace élève. Au départ, aucun élève n'est choisi et il attend un code.

À savoir

  • La page montre les codes de connexion de tous vos élèves : ne pas la projeter en classe.
  • La liste ne lit que le prénom, les deux lettres et le code : ni note, ni aménagement.
  • La page se trouve aussi par la recherche (Ctrl K), comme toutes les pages du menu.
  • Dans une fenêtre étroite (ou sur tablette), la liste passe au-dessus et le téléphone perd son cadre.

Lire la liste des codes

OrdinateurVision élève › liste de gauche

Retrouver d'un coup d'œil le code de n'importe quel élève, classe par classe, et l'élève témoin de chaque classe.

  1. Une classe par bloc, rangées par nom. La pastille a la couleur du niveau ; le nombre est celui des élèves qui ont un code.
  2. L'élève témoin vient en tête de sa classe, avec l'étiquette témoin : c'est lui qu'on ouvre pour voir tout ce que la classe peut ouvrir.
  3. Puis les élèves par ordre alphabétique : prénom et deux lettres, et le code à six chiffres à droite.
  4. Cliquer l'en-tête d'une classe la replie, et la suivante remonte. Recliquer la rouvre.

À savoir

  • Un élève sans code de connexion, ou sans classe, n'apparaît pas ; une classe sans élève non plus. Sans aucun code : « Aucun élève avec un code de connexion. »
  • Les classes repliées ne sont pas retenues : en revenant sur la page, tout est déplié. Pendant une recherche aussi.
  • Les codes se donnent aux élèves depuis Suivi élèves (cartes QR à imprimer) ; un élève devient témoin par sa fiche, menu Profil.

Chercher un élève, un code ou une classe

OrdinateurVision élève › Élève, code ou classe

Dans une longue liste, aller droit à l'élève voulu : par son prénom, par le début de son code, ou en ne gardant qu'une classe.

  1. Taper un prénom dans la recherche : « eloise » trouve Éloïse MA, sans se soucier des accents ni des majuscules.
  2. Taper le début d'un code : « 48 » garde les élèves dont le code commence par 48, dans toutes les classes.
  3. Taper le nom d'une classe : « 4b » garde toute la 4B.
  4. Si rien ne correspond : « Aucun élève ne correspond. » Effacer la recherche rend la liste entière.

À savoir

  • Le prénom se cherche par n'importe quel morceau (« lo » trouve Lou, Chloé, Malo…) ; le code, seulement par son début.
  • La classe se cherche par son nom complet, espaces ignorés (« 4 b » marche aussi) ; « 4 » seul cherche dans les prénoms et les codes.
  • Le nombre à côté de chaque classe devient celui des élèves trouvés.

Ouvrir l'espace d'un élève

OrdinateurVision élève › clic sur un élève

Voir l'espace d'un élève précis, déjà connecté, sans taper son code : ce qu'il voit de ses notes, de sa carte à tampons, de ses cours.

  1. Cliquer un élève dans la liste : sa ligne passe en bleu, et le téléphone charge son espace.
  2. Au-dessus du téléphone : son prénom et son code. Le bouton Autre code apparaît.
  3. L'espace s'ouvre déjà connecté, sur l'accueil : c'est exactement ce que voit Inès.
  4. Le téléphone se manipule comme celui de l'élève : toucher Tampons ouvre sa carte.
  5. Cliquer un autre élève : le téléphone repart sur l'espace de celui-ci.

À savoir

  • Le téléphone charge la vraie page élève, avec les mêmes données : rien n'est imité.
  • Un élève ordinaire ne voit que ce que sa classe a ouvert (Classes, Visibilité élèves) ; l'élève témoin voit tout. De quoi vérifier un réglage avant de le donner à la classe.
  • Votre visite n'est pas comptée comme une connexion de l'élève : ses connexions, dans sa fiche, ne bougent pas.
  • Recliquer le même élève recharge son espace.

Taper un code à la main

OrdinateurVision élève › Autre code

Essayer un code tel qu'un élève le taperait : un code noté sur une carte, ou donné par un élève qui n'arrive pas à entrer.

  1. Un élève est ouvert. Cliquer Autre code.
  2. Le téléphone revient à l'écran du code ; plus aucun élève n'est surligné et le bouton disparaît.
  3. Taper les six chiffres dans le téléphone, comme le ferait l'élève.
  4. Toucher Voir mes résultats : l'espace de cet élève s'ouvre.
  5. Au-dessus, la page n'affiche pas de nom : elle ne sait pas quel code a été tapé dans le téléphone.

À savoir

  • Au départ, sans élève choisi, le téléphone est déjà sur l'écran du code : Autre code n'apparaît qu'une fois un élève ouvert depuis la liste.
  • Un code faux affiche « Code incorrect. Vérifie et réessaie. », comme chez l'élève.
  • Le bouton Quitter de l'espace élève ramène aussi à l'écran du code.

Recharger, ou ouvrir dans un onglet

OrdinateurVision élève › Recharger / Onglet

Revoir l'espace après un changement fait ailleurs, ou le regarder en grand dans un onglet à part.

  1. Recharger relance l'espace de l'élève ouvert, par exemple après lui avoir donné un tampon.
  2. L'espace revient sur l'accueil, à jour : le tampon donné entre-temps est compté.
  3. Onglet ouvre le même espace dans un nouvel onglet du navigateur, déjà connecté.
  4. L'espace s'y affiche comme sur un ordinateur : une colonne au milieu de la page.

À savoir

  • L'espace élève ne se met pas à jour tout seul (sauf la carte à tampons, ouverte) : recharger après un changement de réglage ou de note.
  • Recharger ramène toujours à l'accueil de l'espace.
  • Sans élève choisi, Onglet ouvre l'écran du code.

Ce que vous faites dans le téléphone compte pour l'élève

OrdinateurVision élève › avertissement sous le titre

Le téléphone n'est pas une copie : il agit sur le vrai compte de l'élève. Savoir ce qui reste, et comment essayer sans rien changer pour un élève.

  1. Sous le titre, l'avertissement : ce que vous faites dans le téléphone (bonus choisi, réponses) compte pour l'élève.
  2. Ici, la carte de Jules est pleine. Toucher un bonus puis le valider…
  3. … le choisit vraiment pour lui : « Bonus enregistré », comme s'il l'avait fait lui-même.
  4. Pour essayer sans toucher à un vrai élève, ouvrir l'élève témoin de la classe.

À savoir

  • Comptent pour l'élève : un bonus choisi, les réponses au questionnaire de la Maison, une photo de TP déposée, un thème gagné ou choisi.
  • Seule votre visite n'est pas comptée : elle n'apparaît pas dans les connexions de l'élève.
  • L'élève témoin est exclu des classements et des statistiques de la classe : ce qu'on fait avec lui ne fausse rien.

Voir aussi : Choisir son bonus · Élève témoin

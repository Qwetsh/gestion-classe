Travail de groupe sur tablette

Sans l'application mobile, le site ouvert sur une tablette ou un téléphone tactile sait mener un TP noté en groupes : nommer le TP, poser le barème, former les groupes, noter chacun, puis lire la synthèse. Le parcours est plus simple que celui de l'application.

Accueil › Travail de groupeTablette ou téléphone tactilePas sur ordinateur

Lancer un travail de groupe

Tablette ou téléphoneSite › Accueil › Travail de groupe

Sur l'accueil du site, deux boutons servent aux TP en groupes : Travail de groupe pour un TP noté sur critères, Épreuve pour les épreuves de l'Académie.

  1. Sous Démarrer une séance, toucher Travail de groupe.
  2. L'écran vert « Travail de groupe » liste les classes : toucher la classe du TP. Annuler, en haut à gauche, abandonne.
  3. L'écran Configuration s'ouvre, au nom de la classe.
  4. Épreuve suit le même chemin, dans un décor sombre et doré : « Sélectionnez la classe pour l'épreuve des Quatre Maisons ».

À savoir

  • Ces boutons n'existent que sur un appareil tactile de 1 024 pixels de large au plus, ou sur le site installé comme application. Sur un ordinateur, ils n'apparaissent pas.
  • L'application mobile reste la voie conseillée : îlots, photos, séance liée et travail sans réseau. Ce parcours n'a ni îlots, ni photos, ni séance liée.
  • Si la classe a l'Académie activée, quatre groupes « maisons » sont créés tout seuls avec leurs membres, qu'on passe par Travail de groupe ou par Épreuve.

Nommer le TP et poser le barème

Tablette ou téléphoneTravail de groupe › Configuration

Le haut de l'écran Configuration : le nom du TP et ses critères de notation, repris d'un modèle de Mes TP ou écrits sur place.

  1. Écrire le Nom de la séance, par exemple « Observation au microscope ».
  2. Toucher un modèle de Mes TP : son barème remplit la liste des critères, et le total s'affiche à droite.
  3. La croix d'un critère le retire.
  4. Pour ajouter un critère : son nom dans « Critère... », ses points dans « Pts », puis +.
  5. Le barème est prêt : « Total: 20 pts ».

À savoir

  • Seuls les modèles du niveau de la classe (et ceux sans niveau) sont proposés.
  • Tant que le TP n'est pas prêt, un message sous le bouton dit ce qui manque : « Nom requis », « Ajoutez des critères », « Créez des groupes ».
  • En mode Académie, une ligne Coefficient Académie (de 0 à 5, par demi-point) s'ajoute.

Former les groupes

Tablette ou téléphoneTravail de groupe › Configuration › Groupes

Le bas de l'écran Configuration : les groupes se forment à la main, élève par élève, ou au hasard d'un seul geste.

  1. + Groupe ajoute « Groupe 1 », puis « Groupe 2 »…
  2. Toucher l'onglet du groupe pour l'ouvrir.
  3. La liste Non assignés montre les élèves sans groupe : un toucher fait entrer l'élève dans le groupe ouvert.
  4. Les membres s'affichent en indigo ; toucher « Lina BO × » le retire. Supprimer retire le groupe.
  5. Pour aller vite : Aléatoire.
  6. Indiquer le nombre d'« Élèves par groupe: », puis OK : toute la classe est répartie au hasard.
  7. Les onglets montrent chaque groupe et son effectif : toucher un onglet pour vérifier, puis Commencer la notation.

À savoir

  • Un élève n'est que dans un groupe : l'ajouter ailleurs le retire du premier.
  • Le bouton reste grisé tant qu'un groupe est vide : « Chaque groupe doit avoir au moins 1 élève ».
  • En mode Académie, les groupes sont les quatre maisons : ni + Groupe, ni Aléatoire, ni suppression.
  • À la création, tous les critères de tous les groupes sont posés à 0 point.

Noter les groupes

Tablette ou téléphoneTravail de groupe › notation

Un groupe à la fois : chaque critère se règle d'un toucher, le malus de conduite se retire, puis on passe au groupe suivant.

  1. Les onglets du haut montrent chaque groupe et son score. Sur un critère, les raccourcis 0 ½ ¾ Max donnent la note d'un coup.
  2. La barre sous la note se colore : verte à partir de 70 %, orange à partir de 40 %, rouge en dessous.
  3. − et + ajustent finement : d'un demi-point si le critère vaut 5 points ou moins, sinon d'un point.
  4. Le Malus conduite retire des points au groupe ; l'encadré passe au rose.
  5. En bas, le TOTAL du groupe ; Groupe suivant → ouvre le suivant.
  6. L'onglet du groupe noté garde son score ; sur le dernier groupe, le bouton devient Terminer la notation.

À savoir

  • Chaque note s'écrit aussitôt dans la base, sans attendre. Limite actuelle : une erreur d'écriture passe inaperçue, une coupure de réseau peut faire perdre un point sans message.
  • Une petite vibration accompagne chaque geste (sur Android ; pas sur iPhone).
  • ← Retour suspend la notation : l'accueil propose alors Reprendre la notation.

Terminer et lire la synthèse

Tablette ou téléphoneTravail de groupe › Terminer la notation

Une fois le dernier groupe noté, la notation se clôt et un écran classe les groupes du meilleur au moins bon.

  1. Sur le dernier groupe, toucher Terminer la notation.
  2. La fenêtre rappelle le « Score final : 15/20 (75%) » : Valider, ou Poursuivre pour revenir.
  3. « Séance terminée » : le TP passe à l'état terminé, ce qui crée sa colonne au carnet.
  4. Les groupes sont classés : rang, membres, score, barre colorée et détail des critères, malus compris.
  5. Lire les trois cases de synthèse (groupes, élèves, moyenne), puis Retour à l'accueil.

À savoir

  • La synthèse ne se rouvre pas une fois fermée : la fiche du TP au bureau, ouverte depuis le carnet, prend le relais.
  • Les critères étant posés à 0 dès la création, la fiche du bureau peut compter tous les groupes comme « notés » dès le départ : vérifier les notes groupe par groupe.
  • Après ← Retour, le bouton Reprendre la notation de l'accueil ne marche que tant que la page n'a pas été rechargée.
  • En épreuve de l'Académie, la fenêtre et la synthèse prennent les couleurs de la maison gagnante et les points vont aux maisons.

Boîte à outils

Douze petits utilitaires, indépendants des classes et des élèves : un QR code à imprimer, des jeux de vocabulaire, un journal, une frise, des documents administratifs, des PDF à découper. Cette première page présente la grille, les QR codes, les jeux et les outils de liens et de vidéo.

La boîte à outils

OrdinateurPlus › Outils

Une grille de douze cartes, une par outil. Chaque outil travaille seul, dans le navigateur : il ne connaît ni les classes ni les élèves de l'application.

  1. Dans le menu, ouvrir Plus puis Outils. La page s'intitule « Boite a outils » et compte les outils disponibles.
  2. Survoler une carte : elle se soulève, son nom passe en indigo. Sous le nom, une courte description de l'outil.
  3. Cliquer la carte : l'outil s'ouvre sous un bandeau qui rappelle son nom et sa description.
  4. Le bouton carré ←, en haut à gauche, ramène à la grille.

À savoir

  • Presque tout se calcule sur l'ordinateur : rien n'est envoyé. Seul le convertisseur YouTube passe par un service extérieur.
  • Quitter un outil efface ce qui n'a été ni téléchargé ni sauvegardé, sauf la frise (gardée automatiquement) et l'historique des documents officiels. Ces sauvegardes restent dans le navigateur de cet ordinateur.
  • La recherche générale du site trouve aussi chaque outil par son nom ou un mot-clé (« frise », « pdf », « qr », « vocabulaire », « youtube ») et l'ouvre directement.
  • Ni catégories ni filtre : l'ordre des cartes est fixe. Les pictogrammes des cartes dépendent de l'ordinateur et changent d'aspect d'un système à l'autre.
  • Plusieurs libellés sont écrits sans accents sur le site (« Boite a outils », « Separateur PDF », « Telecharger ») : le guide les recopie tels quels.
  • Une carte porte le nom d'un film connu dont l'outil imite le générique : le guide l'appelle Intro animée.
  • Cinq outils prennent toute la largeur de l'écran (journal, intro, frise, documents officiels, séparateur PDF) ; les autres tiennent dans une colonne centrale.

QR Code

OrdinateurPlus › Outils › QR Code

Transformer un lien en QR code à imprimer ou à coller dans une fiche, avec au centre un mot (« Correction », « Vidéo »…) pour que les élèves sachent ce qu'ils vont ouvrir.

  1. Taper ou coller le lien dans Lien ou texte : le QR code se dessine aussitôt, sans bouton à cliquer.
  2. Choisir la Couleur du code : noir, bleu, rouge ou vert. Le fond reste blanc.
  3. Cliquer un Mot central : Correction, Application, Documents, Exercice, Leçon, Évaluation, Ressource ou Vidéo. Recliquer le même le retire. Logo central › Ajouter pose une image à la place.
  4. Télécharger PNG enregistre l'image ; Copier la place dans le presse-papiers pour la coller dans un document ou un courriel.

À savoir

  • Un seul élément au centre : poser un logo retire le mot, et l'inverse. Avec l'un ou l'autre, le code passe en correction d'erreur haute : il reste lisible malgré ce qui le cache.
  • L'image fait 1024 × 1024 pixels (« qrcode-1024px.png »), avec une marge blanche autour.
  • Copier ne confirme rien à l'écran, et certains navigateurs refusent la copie d'image sans le dire : en cas de doute, télécharger le PNG.
  • Tout se calcule sur l'ordinateur : le lien n'est ni envoyé ni gardé.
  • Le QR « version couleur » imprimé tout seul sur les documents de Mes cours est une autre fonction.

Voir aussi : Lecteur QR Code · documents ouverts par QR code

Lecteur QR Code

OrdinateurPlus › Outils › Lecteur QR Code

Lire un QR code avec la webcam ou sur une image, par exemple pour vérifier où mène un code avant de l'imprimer.

  1. Cliquer Scanner avec la camera : le navigateur demande l'accès à la webcam.
  2. Présenter le QR code dans le cadre de visée. Fermer arrête la caméra sans rien lire.
  3. Dès que le code est reconnu, la caméra s'éteint et le contenu s'affiche sous Resultat.
  4. Copier copie le texte lu ; Scanner un autre relance la caméra.
  5. Sans webcam : Ou importer une image lit le code sur une capture d'écran ou une photo.

À savoir

  • Le texte lu n'est jamais ouvert tout seul : on le lit et on le copie. C'est une bonne protection contre un code piégé.
  • En cas d'échec : « Impossible d'acceder a la camera. Verifiez les permissions. » ou « Aucun QR code detecte dans cette image. »
  • Réimporter exactement la même image juste après ne relance pas la lecture : choisir un autre fichier entre les deux.
  • La lecture se fait entièrement sur l'ordinateur.

Mots croisés : choisir la source et saisir ses mots

OrdinateurPlus › Outils › Mots croisés

Fabriquer en quelques secondes une grille de mots croisés imprimable avec les mots du chapitre et leurs définitions.

  1. Dans Source des mots, garder Saisie libre, choisie à l'ouverture. Les six autres cartes sont des listes de vocabulaire du collège.
  2. Taper un Mot et, si on veut, sa Définition (optionnelle), puis Entrée ou +. Le mot rejoint la liste numérotée.
  3. Plus rapide : Mode texte, une ligne par mot au format « MOT : définition », puis Valider et revenir. Importer Excel lit un tableau : mots en colonne A, définitions en colonne B.
  4. Survoler un mot puis cliquer sa croix pour le retirer ; Tout effacer vide la liste.
  5. Cliquer Générer les mots croisés : la grille apparaît dessous.

À savoir

  • Les mots passent en capitales et seules les lettres sont gardées, accents compris : « ÊTRE VIVANT » devient « ÊTREVIVANT ». Un mot de moins de deux lettres est ignoré.
  • Le « Mode texte » remplace toute la liste ; l'import Excel (.xlsx, .xls ou .csv, première feuille) ajoute à la suite.
  • Une définition laissée vide s'imprime « — ».
  • Changer de source efface la grille en cours. Rien n'est sauvegardé : quitter la page perd la liste.
  • Les grilles et les listes sont un peu serrées : l'outil tient dans la colonne étroite du site.

Mots croisés : listes de vocabulaire du collège

OrdinateurMots croisés › SVT Collège…

Tirer au hasard des termes d'une matière, déjà écrits avec leur définition : les définitions deviennent les indices de la grille.

  1. Choisir une matière : SVT, français, anglais, histoire-géographie, maths ou allemand. Chaque carte annonce son nombre de termes.
  2. Dans Thèmes, cliquer un ou plusieurs des dix thèmes. Sans sélection, tous les thèmes sont pris.
  3. Régler le Nombre de mots avec le curseur, de 4 à 30.
  4. Cliquer Générer les mots croisés : les termes sont tirés au hasard, sans doublon.

À savoir

  • En anglais et en allemand, une carte Options propose « Masquer les formes verbales dans les définitions » : seule la traduction française s'affiche.
  • Chaque clic sur « Générer » ou « Regénérer » tire d'autres mots. Sous la grille, le volet « Voir les N mots sélectionnés » liste les mots tirés et leurs définitions complètes : pratique pour le corrigé.
  • Les thèmes de SVT : cellule et vivant, nutrition et digestion, respiration et circulation, reproduction, génétique, évolution et classification, écosystèmes, géologie, système immunitaire, environnement.
  • Les listes sont écrites dans l'application : on ne peut ni les compléter ni les corriger depuis le site.

Mots croisés : grille, solution et impression

OrdinateurMots croisés › sous les réglages

Vérifier la grille, l'afficher avec ou sans les lettres, en tirer une autre, puis l'imprimer pour la classe.

  1. La barre indique le nombre de mots placés et la taille de la grille. Les définitions sont rangées en Horizontalement et Verticalement.
  2. Voir solution écrit les lettres dans la grille ; le bouton passe au vert et devient Masquer solution.
  3. Regénérer propose une autre disposition (et d'autres mots si la source est une liste de vocabulaire).
  4. Imprimer ouvre un onglet avec la grille vide et les définitions, et lance l'impression.

À savoir

  • Chaque mot doit croiser un mot déjà posé : l'outil essaie quinze dispositions et garde la plus remplie, puis la plus compacte. Un mot sans lettre commune est écarté, avec l'avertissement « N mots non placés ».
  • La feuille imprimée n'a jamais les lettres, même si la solution est affichée. Pour un corrigé papier, faire une capture d'écran avec « Voir solution ».
  • Pas d'export PDF dédié, mais « Enregistrer en PDF » dans la fenêtre d'impression du navigateur convient.
  • Si le navigateur bloque les fenêtres surgissantes, « Imprimer » ne fait rien : autoriser le site.

Mots mêlés : choisir la source et saisir ses mots

OrdinateurPlus › Outils › Mots mêlés

Cacher des mots dans une grille de lettres, dans tous les sens, pour une fiche d'entraînement au vocabulaire.

  1. Dans Source des mots, garder Saisie libre (« Vos propres mots ») ou choisir une matière.
  2. Taper un Mot, puis Entrée ou + : il s'ajoute en étiquette à côté des autres.
  3. Ou Mode texte : un mot par ligne, puis Valider et revenir. Importer Excel lit la colonne A d'un tableau.
  4. Cliquer Générer les mots mêlés.

À savoir

  • Pas de définitions en saisie libre : seulement les mots.
  • Mêmes règles de nettoyage que pour les mots croisés : capitales, lettres seules, deux lettres au moins.
  • Changer de source efface la grille ; rien n'est sauvegardé.

Mots mêlés : grille, solution et impression

OrdinateurMots mêlés › sous les réglages

Contrôler la grille, montrer la solution, imprimer la fiche.

  1. La barre donne le nombre de mots placés et la taille de la grille, toujours carrée.
  2. Voir solution : les lettres des mots passent en blanc sur fond indigo.
  3. La carte Mots à trouver liste les mots, avec leur définition si l'option est active.
  4. Imprimer : grille sans solution et liste des mots sur trois colonnes. Regénérer tire une autre grille.

À savoir

  • Les mots sont posés dans les huit directions (à l'endroit, à l'envers, en diagonale), les plus longs d'abord ; deux mots peuvent partager une lettre.
  • La grille fait au moins 10 × 10 et grandit avec le nombre et la longueur des mots.
  • Les cases vides sont remplies de lettres sans accent : un mot accentué (« ÉCOSYSTÈME ») se repère donc plus facilement à ses accents.
  • Les mots non placés sont signalés au-dessus de la grille (« N mots non placés »).

Iframe

OrdinateurPlus › Outils › Iframe

Obtenir le code qui intègre une page web (simulation, vidéo, quiz) dans une page de l'ENT ou un site qui accepte le HTML, et vérifier l'aperçu.

  1. Coller l'adresse dans Lien à intégrer.
  2. Choisir le Ratio : 16:9, 4:3, 1:1, Téléphone ou Plein. Avec Plein, régler la Hauteur (px) (500 au départ).
  3. Les cases Sans bordure et Plein écran sont cochées d'avance.
  4. Copier, à droite de Code HTML : le bouton affiche « Copié ! » un instant. Coller ce code dans la page de destination.
  5. L'Aperçu montre la page intégrée au ratio choisi.

À savoir

  • Beaucoup de sites refusent d'être intégrés : l'aperçu reste alors vide ou affiche une erreur, et le code ne marchera pas mieux ailleurs. L'outil ne le signale pas.
  • L'adresse n'est pas vérifiée : une adresse fausse donne quand même un code.
  • Le code prend toute la largeur disponible et ne charge la page qu'au moment où elle devient visible.

Voir aussi : pages intégrées dans les tableaux de séance

YouTube → MP3 / MP4

OrdinateurPlus › Outils › YouTube → MP3 / MP4

Récupérer la bande-son (MP3) ou la vidéo (MP4) d'une vidéo YouTube, pour la passer en classe sans connexion et sans publicité.

  1. Coller le lien dans Lien YouTube : lien classique, lien court ou Shorts. Une adresse qui ne ressemble pas à YouTube affiche « Lien YouTube invalide ».
  2. Choisir le Format : MP3 (Audio) ou MP4 (Vidéo).
  3. Cliquer Convertir en MP3 : « Conversion en cours… » pendant l'attente.
  4. « Fichier prêt ! » : Télécharger MP3 enregistre le fichier, dont le nom s'affiche dessous.

À savoir

  • Limite actuelle : l'outil dépend d'un service de conversion extérieur et payant, que le serveur de l'application interroge. Si ce service change, sature ou ferme, la conversion échoue (« Impossible de contacter le service de conversion. ») sans que l'application n'y puisse rien. Quand le service n'est pas branché, l'outil le dit dès l'ouverture et le bouton reste grisé.
  • Quota commun : 500 conversions par mois pour tous les enseignants de l'application, compteur affiché en bas. Au-delà : « Limite mensuelle atteinte. Réessayez le mois prochain. »
  • Le MP4 n'est ouvert qu'à certains comptes, réglés sur le serveur ; pour les autres, le bouton est grisé avec la mention « MP4 : accès restreint ».
  • Réservé aux enseignants connectés. Changer le lien ou le format efface le résultat. Si le téléchargement direct échoue, le fichier s'ouvre dans un nouvel onglet.

Intro animée : texte qui défile en perspective

OrdinateurPlus › Outils › carte à l'étoile

Projeter en ouverture de séance ou de projet un générique de cinéma : une phrase d'introduction, un logo, puis un long texte jaune qui défile en s'éloignant dans un ciel étoilé.

  1. Remplir le formulaire : Texte d'intro (bleu), URL du logo (vide : logo fourni), Épisode, Titre et Texte du crawl, le texte qui défile. Une ligne vide sépare deux paragraphes.
  2. Régler la Durée du crawl (s) (80 au départ, de 20 à 300). Une musique peut venir d'une adresse ou d'un fichier (Ou fichier local) ; une case centre le texte.
  3. Cliquer ▶ Play : l'animation remplace le formulaire.
  4. Sur fond étoilé : la phrase d'intro en bleu, puis le logo qui recule, puis le texte jaune qui monte en s'éloignant.
  5. × Quitter, ou la touche Échap, ramène au formulaire.

À savoir

  • Sur le site, la carte et le formulaire portent le nom du film dont l'outil imite le générique, et les champs arrivent préremplis avec le texte d'origine, en anglais : tout remplacer par son propre texte.
  • La musique fournie démarre cinq secondes après « Play ». Un fichier choisi sur l'ordinateur passe avant une adresse, qui passe avant la musique fournie. Si le navigateur bloque le son, l'animation joue en silence, sans message.
  • Le formulaire tutoie (« Remplis les champs… ») : il a été écrit pour être manipulé aussi par des élèves.
  • Rien n'est sauvegardé et il n'y a pas d'export vidéo : l'intro se joue en direct. Pour le plein écran, utiliser celui du navigateur (touche F11).
  • Sans internet, les titres perdent leur police décorative, chargée depuis un site extérieur.
  • Le texte prérempli et la musique fournie reprennent une œuvre protégée : en classe, l'usage reste celui d'une courte citation pédagogique.

Groupes, salles et plans

Les groupes durables d'une classe (demi-groupes, latinistes) se répartissent du bout du doigt ; les salles dessinées sur le site se consultent ; le plan de classe se construit en touchant un élève, puis sa place. Tout marche sans réseau.

Classes › une classe › Groupes, Plan de classeTéléphoneMarche sans réseau

La section Groupes de la fiche de classe

TéléphoneClasses › une classe › Groupes

Les groupes durables d'une classe (demi-classe une semaine sur deux, latinistes, groupe de besoin) et leurs effectifs. Ce ne sont pas les groupes de TP, éphémères et notés, qui ont leur propre écran en séance.

  1. Dans la fiche de la classe, descendre à la section Groupes, entre Eleves et Plan de classe.
  2. Chaque groupe : une pastille à sa couleur, son nom et son effectif. Une dernière ligne grise compte les élèves non affectés.
  3. Toucher Gérer, ou n'importe quelle ligne de groupe, pour ouvrir l'écran Groupes.
  4. Une classe sans groupe montre la carte Aucun groupe : la toucher pour en créer.

À savoir

  • La section se met à jour à chaque retour sur la fiche.
  • Tout est lu dans le téléphone : cela marche sans réseau.

L'écran Groupes

TéléphoneClasses › une classe › Groupes › Gérer

Répartir les élèves entre les groupes de la classe par simples touchers : une carte par groupe, et une carte pour les élèves sans groupe.

  1. En haut : le chevron de retour, le titre Groupes et le nom de la classe, puis ··· (actions de masse) et + (nouveau groupe).
  2. La phrase d'aide rappelle les deux gestes : toucher pour déplacer, appui long pour sélectionner plusieurs élèves.
  3. Une carte par groupe, bordée à gauche de sa couleur : nom, effectif, bouton ··· de réglage, et les élèves en pastilles.
  4. En dernier, la carte en pointillés Non affecté, pour les élèves sans groupe.
  5. Revenir à la fiche de la classe avec le chevron.

À savoir

  • Les pastilles montrent le vrai nom si le téléphone le connaît, sinon le pseudonyme. Les pastilles PAP, PPRE, PAI n'apparaissent pas ici.
  • Tout s'enregistre dans le téléphone, puis part au site à la synchronisation : l'écran marche sans réseau.
  • Avec deux groupes exactement, la phrase d'aide dit « le faire changer de groupe » ; sinon « choisir son groupe ».

Créer les premiers groupes

TéléphoneClasses › une classe › Groupes (sans groupe)

Une classe sans groupe se coupe en deux en un geste.

  1. L'écran Groupes d'une classe sans groupe montre la carte Aucun groupe et trois boutons.
  2. Créer un groupe vide ouvre la feuille Nouveau groupe ; Créer depuis un plan de salle (s'il existe une salle) part d'un plan de classe.
  3. Toucher Créer des demi-groupes (G1 / G2).
  4. Deux groupes apparaissent : Groupe 1 (indigo) reçoit la première moitié de la liste alphabétique, Groupe 2 (vert) la seconde.

À savoir

  • La liste est triée par pseudonyme, donc par prénom ; s'il y a un nombre impair d'élèves, le groupe 1 prend l'élève de plus.
  • Le bouton des demi-groupes est grisé si la classe n'a aucun élève.
  • La répartition se retouche ensuite élève par élève.

Changer un élève de groupe

TéléphoneGroupes › toucher un élève

Faire passer un élève d'un groupe à l'autre d'un seul toucher.

  1. Avec deux groupes exactement : toucher la pastille d'un élève.
  2. Il passe aussitôt dans l'autre groupe, avec le point de sa nouvelle couleur ; les effectifs se mettent à jour.
  3. Un bandeau vert confirme « Lina BO → Groupe 2 », avec Annuler pendant 4 secondes.
  4. Pour un élève non affecté, ou quand la classe a un seul groupe ou plus de deux, le toucher ouvre une feuille pour choisir son groupe.

À savoir

  • Un élève n'est que dans un seul groupe à la fois dans une classe : le déplacer le retire de tous les autres.
  • Avec un seul groupe, toucher un élève non affecté l'y envoie directement.
  • Pas de vibration sur cet écran.

Choisir le groupe : Déplacer vers…

TéléphoneGroupes › feuille de choix

Une feuille qui monte du bas pour choisir le groupe de destination d'un ou plusieurs élèves.

  1. Toucher un élève (ici dans une classe à trois groupes) : la feuille s'ouvre.
  2. En titre, le nom de l'élève (ou « Déplacer 3 élèves »). Une ligne par groupe avec son effectif, puis Non affecté pour retirer l'élève de tout groupe.
  3. Toucher le groupe voulu.
  4. L'élève rejoint le groupe et le bandeau vert propose Annuler. Toucher le fond ferme la feuille sans rien changer.

À savoir

  • La même feuille sert au bouton Déplacer vers… de la sélection multiple.

Sélectionner plusieurs élèves

TéléphoneGroupes › appui long sur un élève

Déplacer d'un coup plusieurs élèves vers le même groupe.

  1. Garder le doigt un tiers de seconde sur un élève : le mode sélection s'active et cet élève est coché.
  2. Toucher d'autres élèves, dans n'importe quelle carte, pour les cocher ou les décocher.
  3. En bas, une barre affiche « 3 sélectionné(s) », Annuler et Déplacer vers….
  4. Toucher Déplacer vers… : la feuille « Déplacer 3 élèves » s'ouvre.
  5. Toucher le groupe : les trois élèves y passent, le bandeau confirme « 3 élèves → Groupe 2 » et le mode sélection se ferme.

À savoir

  • Annuler dans la barre quitte le mode sans rien changer.
  • Si l'on décoche tout, le mode reste actif jusqu'à Annuler ; Déplacer vers… est alors grisé.

Échanger deux élèves

TéléphoneGroupes › sélection › Échanger

Intervertir deux élèves de groupes différents en un geste : Lina passe dans le groupe de Noé, et Noé dans celui de Lina.

  1. Appui long sur un premier élève.
  2. Toucher un second élève, dans un autre groupe (ou dans Non affecté).
  3. Le bouton Échanger apparaît dans la barre du bas : le toucher.
  4. Les deux élèves changent de groupe ; le bandeau confirme « Lina BO ⇄ Noé MA », avec Annuler.

À savoir

  • Le bouton n'apparaît que si exactement deux élèves sont cochés et qu'ils ne sont pas dans le même groupe.

Annuler un déplacement

TéléphoneGroupes › bandeau vert

Revenir sur un geste malheureux sans chercher l'élève.

  1. Un toucher de trop : Tom passe dans l'autre groupe.
  2. Le bandeau vert descend en haut de l'écran : « Tom SA → Groupe 1 ».
  3. Toucher Annuler dans les 4 secondes.
  4. L'élève revient dans le groupe où il était. Sans geste, le bandeau remonte seul au bout de 4 secondes.

À savoir

  • Seul le dernier geste s'annule : un toucher, un déplacement multiple ou un échange.
  • La répartition automatique, l'équilibrage et l'import depuis un plan de salle ne proposent pas d'annulation.

Nouveau groupe

TéléphoneGroupes › +

Ajouter un groupe : latinistes, groupe de besoin, troisième groupe.

  1. Toucher + en haut à droite.
  2. La feuille Nouveau groupe monte, le clavier sur le nom déjà proposé : « Groupe 3 ».
  3. Taper le nom voulu.
  4. Toucher une pastille de couleur : elle s'entoure d'un anneau sombre.
  5. Toucher Créer. Toucher le fond ferme sans créer.
  6. Le groupe, vide, se place après les autres : y envoyer les élèves par un toucher.

À savoir

  • Huit couleurs : indigo, vert, ambre, rose, bleu, violet, turquoise, rouge. La première couleur pas encore prise dans la classe est proposée.
  • Le nom compte 40 caractères au plus ; Créer est grisé s'il est vide.
  • Le site affiche la même couleur, dans sa propre nuance.

Modifier un groupe

TéléphoneGroupes › ··· d'un groupe

Renommer un groupe, changer sa couleur, le remplir depuis un plan de salle ou le supprimer.

  1. Toucher ··· dans l'en-tête de la carte du groupe.
  2. La feuille Modifier le groupe s'ouvre : le nom est rempli, la couleur actuelle cerclée.
  3. Changer le nom ou toucher une autre couleur.
  4. Dans la même feuille : Remplir depuis un plan de salle… (s'il existe une salle) et Supprimer, en rouge.
  5. Toucher Enregistrer : la carte prend la nouvelle couleur.

À savoir

  • Enregistrer sans rien changer ferme simplement la feuille.
  • Le clavier ne s'ouvre pas tout seul ici : toucher le champ pour renommer.

Supprimer un groupe

TéléphoneGroupes › ··· d'un groupe › Supprimer

Retirer un groupe devenu inutile.

  1. Dans la feuille du groupe, toucher Supprimer.
  2. L'alerte Supprimer « Latinistes » ? prévient : les élèves redeviendront non affectés, les séances passées de ce groupe redeviendront « classe entière », les plans de ce groupe seront supprimés.
  3. Toucher Supprimer, ou Annuler.
  4. La carte disparaît ; ses élèves rejoignent Non affecté.

À savoir

  • Les séances déjà faites avec ce groupe sont gardées, rattachées à la classe entière.
  • La suppression part au site à la synchronisation : elle marche sans réseau.

Les actions de masse

TéléphoneGroupes › ··· en haut à droite

Réunir en un menu les gestes qui touchent toute la classe.

  1. Toucher ··· dans l'en-tête de l'écran.
  2. La feuille Actions propose : Répartir automatiquement…, Créer un groupe depuis un plan de salle…, Équilibrer les non affectés.
  3. Une ligne qui ne peut pas servir est grisée : sans groupe, pas de répartition ni d'équilibrage ; sans salle, pas d'import depuis un plan.

À savoir

  • Aucune de ces actions ne propose d'annulation : la répartition est remplacée.

Répartir automatiquement

TéléphoneGroupes › ··· › Répartir automatiquement…

Refaire toute la répartition d'un geste, dans les groupes existants.

  1. Dans la feuille Actions, toucher Répartir automatiquement….
  2. La feuille prévient : elle remplace la répartition actuelle des groupes avec tous les élèves de la classe.
  3. Trois façons : Moitié alphabétique coupe la liste en tranches qui se suivent, Alternée donne un élève sur deux (un sur trois avec trois groupes…), Aléatoire mélange puis coupe.
  4. Toucher la façon voulue, ici Alternée.
  5. Toute la classe est redistribuée, à un élève près ; plus personne n'est non affecté.

À savoir

  • La liste suit l'ordre des pseudonymes, donc des prénoms.
  • « A–L / M–Z » n'est qu'une indication : avec trois groupes, la liste est coupée en trois tranches.
  • Pas de confirmation supplémentaire ni d'annulation : la répartition précédente est perdue.

Créer ou remplir un groupe depuis un plan de salle

TéléphoneGroupes › ··· › Créer un groupe depuis un plan de salle…

Quand une demi-classe a déjà sa salle et son plan, en tirer le groupe sans retaper la liste.

  1. Trois chemins : Créer depuis un plan de salle (classe sans groupe), la feuille Actions, ou Remplir depuis un plan de salle… dans la feuille d'un groupe.
  2. La feuille Depuis quel plan de salle ? explique : les élèves placés dans le plan de cette classe pour la salle choisie rejoignent le groupe.
  3. Toucher la salle ; chaque ligne rappelle ses rangées × colonnes.
  4. L'alerte Import terminé donne le nombre d'élèves qui ont rejoint le groupe.
  5. Créé depuis les actions, le groupe porte le nom de la salle.

À savoir

  • Les élèves placés quittent leurs autres groupes ; les élèves déjà dans le groupe n'en sont pas retirés.
  • Pas d'annulation.

Équilibrer les non affectés

TéléphoneGroupes › Non affecté › Équilibrer

Placer d'un coup les élèves restés sans groupe, des nouveaux arrivants par exemple, en gardant des groupes de même taille.

  1. Trois élèves sont arrivés : ils attendent dans Non affecté.
  2. Toucher Équilibrer (la balance) dans l'en-tête de la carte.
  3. Chacun part, l'un après l'autre, dans le groupe le moins nombreux : les deux groupes finissent à égalité.
  4. La même action existe dans ··· › Équilibrer les non affectés ; s'il n'y a personne à placer : « Rien à équilibrer ».

À savoir

  • Les élèves sont pris dans l'ordre des pseudonymes ; à égalité d'effectif, le premier groupe l'emporte.
  • Le bouton n'apparaît que s'il reste des non affectés et qu'il existe au moins un groupe.
  • Pas d'annulation.

Un élève dans deux groupes

TéléphoneGroupes › élève marqué !

Régler le cas rare où un élève se retrouve dans deux groupes : des changements faits sans réseau sur deux appareils, puis réunis par la synchronisation.

  1. Un encadré ambre l'annonce en haut de l'écran : « Certains élèves (marqués « ! ») sont dans plusieurs groupes après une synchronisation. »
  2. L'élève apparaît dans chacune de ses cartes, suivi d'un ! ambre.
  3. Le toucher dans la carte à garder.
  4. Il quitte les autres groupes ; le bandeau vert propose Annuler comme pour un déplacement.

À savoir

  • Le toucher garde toujours la carte touchée, quel que soit le nombre de groupes.

Mes salles

TéléphoneFiche de classe › Creer une salle (sans salle)

Consulter les salles de l'enseignant et la taille de leur grille. Les salles se dessinent sur le site ; le téléphone les lit.

  1. Tant qu'il n'existe aucune salle, la fiche de classe propose Creer une salle (le démarrage d'une séance propose de même Configurer une salle).
  2. L'écran Mes salles renvoie vers le site : « Créez vos salles depuis l'application web, puis synchronisez. »
  3. Une fois les salles créées et synchronisées : une carte par salle, avec ses rangées × colonnes.
  4. Toucher une salle pour voir son aperçu. On revient par le geste ou le bouton retour du téléphone.

À savoir

  • Les salles n'ont pas d'onglet. Dès qu'une salle existe, aucun bouton du téléphone ne ramène à cet écran.
  • Créer, modifier, supprimer une salle se fait uniquement sur le site.

L'aperçu d'une salle

TéléphoneMes salles › une salle

Vérifier la disposition d'une salle, places et allées, telle qu'elle a été dessinée sur le site.

  1. Informations : le nom de la salle et sa disposition, « 5 rangees × 7 colonnes ».
  2. Apercu du plan : chaque place en indigo pâle ; les cases désactivées sur le site (allées) en gris.
  3. La légende compte les places et les allées.
  4. Un encart rappelle : pour modifier ou supprimer la salle, passer par le site.
  5. Revenir avec ← Retour.

À savoir

  • Consultation seule ; la fiche s'affiche sans réseau.
  • Ici le tableau est dessiné en haut de la grille. Dans l'éditeur de plan, en séance et sur l'écran projeté, il est en bas : la dernière rangée est le devant de la salle.

Ouvrir le plan d'une classe

TéléphoneClasses › une classe › Plan de classe

Chaque classe a un plan par salle. La section Plan de classe de la fiche les ouvre.

  1. Dans la fiche de la classe, descendre à Plan de classe : toutes les salles de l'enseignant y sont listées.
  2. Chaque ligne : le nom de la salle et sa taille, « 5 x 7 places ».
  3. Toucher une salle.

À savoir

  • Toutes les salles sont proposées, qu'un plan existe déjà ou non ; ouvrir une salle crée un plan vide si besoin.
  • Sans aucune salle : « Aucune salle configuree » et le lien Creer une salle.

L'éditeur de plan

TéléphonePlan de classe › une salle

Placer chaque élève de la classe à sa place dans la salle. Ce plan est celui que montre la séance.

  1. En haut : ← Retour, le titre « Plan - Salle 310 » et Reinitialiser en rouge.
  2. Le nom de la classe et la consigne : « Appuyez sur un eleve, puis sur une place ».
  3. Au milieu, la grille de la salle, qui défile si la salle est grande.
  4. En bas, un panneau fixe : les élèves qui n'ont pas encore de place.
  5. Revenir avec ← Retour.

À savoir

  • Pas de bouton Enregistrer : chaque geste s'enregistre aussitôt dans le téléphone, même sans réseau. Un voile blanc passe un instant à chaque enregistrement.
  • Point connu à ce jour : un plan déjà envoyé au site, puis retouché sur le téléphone, peut être remplacé par la version du site à la synchronisation suivante. Pour un plan durable, le faire ou le vérifier sur le site.
  • Pas de vibration dans cet éditeur.

TéléphoneÉditeur de plan › grille

Les élèves à placer

TéléphoneÉditeur de plan › panneau du bas

Voir qui n'a pas encore de place et choisir l'élève à placer.

  1. Le titre compte les élèves sans place : « Élèves à placer (4) ».
  2. Faire défiler la rangée de pastilles d'un balayage horizontal.
  3. Toucher une pastille : elle devient indigo et le titre dit « Appuyez sur une place libre ».
  4. La toucher de nouveau la libère.
  5. Quand tout le monde est placé, une coche verte : « Tous les élèves sont placés ».

À savoir

  • Seuls les élèves sans place figurent dans la rangée : pour déplacer un élève déjà assis, le retirer d'abord de sa place.

Placer un élève

TéléphoneÉditeur de plan › élève puis place

Asseoir un élève sur une place libre : toucher l'élève, puis la place.

  1. Toucher la pastille de l'élève dans le panneau du bas : elle devient indigo.
  2. Toutes les places libres s'éclairent, bordées de pointillés indigo.
  3. Toucher la place voulue.
  4. L'élève apparaît dans la case et quitte le panneau ; le compteur passe à « 18 / 18 eleves places ».

À savoir

  • Toucher une place libre sans élève choisi ne fait rien.
  • Toucher une place occupée propose de retirer l'élève : on ne remplace pas un élève par un autre et on n'échange pas deux places d'un geste.

Retirer un élève de sa place

TéléphoneÉditeur de plan › place occupée

Libérer une place : élève parti, changement de place.

  1. Toucher la case d'un élève placé.
  2. L'alerte Place occupee : « Lina BO est a cette place. Que voulez-vous faire ? »
  3. Toucher Retirer, ou Annuler.
  4. La case redevient libre et l'élève revient dans le panneau du bas, prêt à être replacé.

À savoir

  • Même avec un élève choisi en bas, toucher une place occupée ouvre cette alerte.
  • Pour changer un élève de place : le retirer, puis le replacer.

Réinitialiser le plan

TéléphoneÉditeur de plan › Reinitialiser

Vider le plan pour le refaire de zéro.

  1. Toucher Reinitialiser, en rouge en haut à droite.
  2. L'alerte Reinitialiser le plan demande : « Voulez-vous retirer tous les eleves du plan ? »
  3. Toucher Reinitialiser, ou Annuler.
  4. Toutes les places redeviennent libres ; tous les élèves reviennent dans le panneau du bas.

À savoir

  • Pas d'annulation après coup.
  • La salle elle-même n'est pas touchée, ni les plans de cette classe dans les autres salles.

Un plan par groupe de classe

TéléphoneÉditeur de plan › Groupe 1

Donner à chaque demi-groupe son propre plan dans une salle, au lieu d'un plan de classe entière à moitié vide.

  1. Pour une classe qui a des groupes, une rangée de pastilles apparaît sous le nom de la classe. L'éditeur s'ouvre toujours sur Classe entière.
  2. Toucher Groupe 1 : la grille et les élèves à placer ne concernent plus que ses membres. Sans plan, un message le dit.
  3. Partir du plan de la classe entière reprend les places des membres du groupe. On peut aussi placer les élèves un par un.
  4. Placer, retirer, Reinitialiser : ces gestes ne touchent que le plan du groupe choisi.
  5. Ici, Jade est avancée au premier rang pour le groupe 1 seulement.
  6. Toucher Classe entière : le plan commun n'a pas bougé.

À savoir

  • En préparation : arrive avec la prochaine version de l'application. Aujourd'hui, les plans par groupe se font sur le site ; la séance sur le téléphone les utilise déjà.
  • Le plan d'un groupe n'existe qu'à partir du premier élève placé. Il est enregistré dans le téléphone, puis envoyé au site à la synchronisation : cela marche sans réseau.
  • En séance avec un groupe, c'est son plan qui s'affiche s'il a au moins un élève placé ; sinon le plan de la classe entière, réduit aux membres du groupe. Réinitialiser le plan d'un groupe fait donc revenir celui de la classe entière.
  • Un élève qui n'est plus dans le groupe laisse sa place libre. Supprimer un groupe supprime ses plans.
